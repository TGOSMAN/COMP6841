Safety and intent

Attacker mindset for defensive awareness

This range is not a guide to misuse radio systems or abuse real infrastructure. It uses synthetic captures, local services, and controlled simulations to raise awareness of threats, failure modes, and defensive engineering choices. Do not transmit, interfere with, or test against systems you do not own or have explicit permission to use.

Programme Blueprint

Progression from basic exposure to SOTA research

The build keeps room for you as the developer: beginner modules are runnable now, while the advanced and expert lanes expose where GNU Radio, C/C++, HDL review, fuzzing, propagation modelling, jamming resilience, and cognitive-radio research can be added.

Basic

Tune, observe, decode

Use civilian tunnel signs and broadcast metadata to practise tuning, waterfall interpretation, OOK/ASK/FSK concepts, time-series inspection, and plain-text recovery.

GNU Radio Integration

Regenerate RF artifacts as developer work

The assessed path uses generated files. Your developer path should be profile-driven: edit signal parameters in Python, C/C++, or GNU Radio, export IQ/SigMF data, convert it into waterfall JSON, and attach it to a challenge without redesigning the website.

1. Profile

Define centre frequency, span, payload, modulation, noise, hopping, and flags in editable Python/C/C++ configuration.

2. Flowgraph

Build GNU Radio Companion generators for OOK/ASK, FSK, audio, hopping, interference, and sensing-style captures.

3. Export

Write `.sigmf-data`, `.sigmf-meta`, waterfall JSON, decoded examples, and expected-answer notes for each module.

4. Bridge

Optionally publish FFT rows over ZeroMQ or a Python socket, then feed rows to the browser waterfall.

5. Script Terminal

Drive subtasks from Python through /api/script/terminal, using the generated client under tools/script_clients/.
