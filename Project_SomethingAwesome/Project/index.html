GNU Radio Integration

Regenerate the RF artifacts later

The assessed path uses generated files. GNU Radio Companion can be used in WSL/Ubuntu to produce real SigMF IQ captures for the same challenge answers.

1. Flowgraph

Build OOK/ASK or FSK teaching bursts with vector sources, noise, file sinks, and QT frequency sinks.

2. Artifact Export

Write `.sigmf-data` samples and `.sigmf-meta` JSON so the tasks stay reproducible without hardware.

3. Optional Bridge

Publish FFT rows over ZeroMQ or a Python socket, then feed rows to the browser waterfall.
